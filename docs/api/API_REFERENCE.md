# API Reference

The authoritative Phase 10 endpoint and lifecycle specification is
[`docs/ai/10_API_AND_SYSTEM_INTEGRATION.md`](../ai/10_API_AND_SYSTEM_INTEGRATION.md).

Base path: `/api/v1`.

The API exposes health, metrics, deterministic session lifecycle operations,
and one validated ETL feature-vector pipeline endpoint. It does not expose
training, evaluation, model reload, manual cloud upload, dashboard, or risk
calculation endpoints.
